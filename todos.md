Yes. askAlpha is a new pre-production AI-enabled conversational analytics application. It introduces a new process in which authorized users submit natural-language questions and receive read-only analytical answers, summaries, KPIs, tables, charts, and reports from governed data sources.

The proposed Phase 1 scope includes the processing of Personal Information relating to TD employees and loan applicants/borrowers. The solution may use Azure OpenAI as part of this processing flow.
