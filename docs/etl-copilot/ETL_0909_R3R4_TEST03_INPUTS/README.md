## Use on Windows

1. Download the ZIP using GitHub's raw-file download action and extract its four
   members directly into a fresh external directory, for example:
   `C:\docs\ETL_0909_R3R4_TEST03_INPUTS`.
2. Give the local Agent that physical directory and instruct it to read
   `START_HERE.md` completely, authenticate the files and read the complete
   incorporated brief and glossary before performing the bounded task.
3. Preserve the stopped TEST02 evidence. The new attempt must authenticate current
   task disposition and the reviewed source baseline. An active writer or source
   drift is handled by the brief's stop rules, not by a duplicate implementation.

A Git checkout of this directory may also supply the inputs at its actual local
path outside both ETL worktrees. The scoped `.gitattributes` disables line-ending
conversion for the pinned inputs; the Agent must still verify their raw identities.
Do not re-save rendered Markdown to reconstruct the files.

The canonical glossary in this package is the one named by START_HERE's SHA-256.
Use this directory's exact file and manifest. Similarly named historical files
elsewhere in the repository are not substitute inputs for TEST03.

Repository source authority for the ETL correction remains the Windows worktree
and evidence chain named in the brief. This `hugan` branch is a delivery location;
it does not become the ETL source baseline. Existing branch/root files are retained.
No product code, execution report, credential or workspace export is added here.
