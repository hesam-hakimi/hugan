# Objective

Inspect the repository and create an evidence-backed implementation program for the requested feature.

# Requirements

- Discover project instructions, architecture decisions, source contracts, and related tests.
- Break the work into small dependency-aware slices.
- Define acceptance criteria, recommended checks, rollback notes, and stop conditions for every slice.
- Identify product or architecture decisions that must be resolved before implementation.

# Exclusions

- Do not modify source files.
- Do not commit, push, open a pull request, merge, or deploy.
- Do not invent missing requirements.

# Final qualification

An independent reviewer must assess scope, security, testability, and evidence quality.
